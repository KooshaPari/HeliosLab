## 5. Controlled pilot

First select the accepted public job. For a workbench, launch two isolated projects and different harnesses, navigate current and archived sessions, inspect a tool error, restart, and resume safely. For configuration tooling, create and change scoped flags/secrets and verify applications observe precisely the intended values. Do not combine incomparable outcomes into one score.

Use fixed versioned inputs and independent outcome oracles. Run matched conditions to isolate mechanisms and a separate idiomatic implementation to compare practical products. Retain failed attempts, intervention logs and infrastructure outcomes. Assign confidence intervals or explicit uncertainty; do not infer a universal winner from one run.

Failure and negative-control cases:

- Secret exposed in a preview or log
- Wrong project receives config
- Stale session becomes writable
- Missing external source works only from a warm cache
- Desktop shell launches the wrong binary
